### 타겟별 핵심 시나리오

- **50대+**: "자녀에게 보내는 메시지가 잔소리처럼 들릴까 걱정" → 부드러운 표현 생성
- **30대**: "상사에게 거절 메시지를 어떻게 보내야 할지 모르겠다" → 격식 있는 메시지 생성
- **20~30대**: "부모님에게 감사/안부 메시지를 잘 전하고 싶다" → 따뜻한 표현 생성
- **20대**: "연인/친구에게 센스 있게 답장하고 싶다" → 캐주얼한 표현 교정

## 3. 핵심 기능

### 메시지 생성 (메인 모드)
- 상황 설명을 입력하면 AI가 적절한 메시지 3개를 생성
- 시나리오(7개)와 톤(4개) 선택으로 맞춤화
- 바로 복사해서 사용 가능

### 말투 교정 (서브 모드)
- 보내려는 문장을 입력하면 AI가 톤을 교정
- 한줄 진단 + 개선 문장 3개 제공
- "상세 분석" 링크를 통해 기존 5카테고리 점수 분석 접근 가능

## 4. 경쟁 포지셔닝

| 서비스 | 특징 | 한계 |
|--------|------|------|
| ChatGPT/Clova | 범용 AI | 한국어 존칭 체계 미흡, 맥락 없음 |
| 네이버 맞춤법 검사 | 맞춤법 교정 | 톤/뉘앙스 분석 없음 |
| **이 말투 어때** | **관계·톤 맞춤 메시지 생성 + 교정** | **토스 생태계 한정** |

### 차별점
1. **세대 간 소통 격차 해소**: 50대+ 타겟에 특화된 시나리오
2. **하이브리드**: 생성(신규) + 교정(기존) 모두 제공
3. **한국어 존칭 특화**: 관계별 적절한 존칭 체계 반영
4. **토스 생태계**: 3천만 사용자 접근성, 별도 설치 불필요
