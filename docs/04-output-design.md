# 04. 결과 화면 설계

## 1. 로딩 화면

| 항목 | 메시지 생성 | 말투 교정 |
|------|----------|----------|
| 메시지 | "AI가 메시지를 만들고 있어요" | "AI가 문장을 살펴보고 있어요" |
| 타임아웃 | 8s load + 3s show (현행 유지) | 동일 |
| 광고 | 인터스티셜 광고 (현행 유지) | 동일 |
| 뒤로가기 | 확인 다이얼로그 (현행 유지) | 동일 |

- 5카테고리 점수 + 10개 세부 항목 (현행 유지)
- 시그널 카드 (현행 유지)
- 교정 모드에서만 접근 가능

## 5. v1 컴포넌트 재사용 매핑

| v1 컴포넌트 | v2 용도 | 변경 사항 |
|------------|---------|----------|
| `CopyCard` | 생성/교정 모드 메시지 카드 | props 일부 변경 (description 제거, text 추가) |
| `ResultCard` | 상세 분석 페이지 | 이동만, 변경 없음 |
| `Progressbar` | 상세 분석 페이지 | 이동만, 변경 없음 |
| `SignalCard` | 상세 분석 페이지 | 이동만, 변경 없음 |
| `ErrorResult` | 전체 에러 처리 | 변경 없음 |

### CopyCard props 변경

```typescript
// v1
interface CopyCardProps {
  label: string;        // 제안 라벨
  description: string;  // 제안 설명
  example: string;      // 복사할 텍스트
}

// v2
interface CopyCardProps {
  label: string;        // 톤 라벨 칩 (예: "부드러운 표현")
  text: string;         // 메시지 본문 (복사 대상)
}
```

## 6. API 응답 스키마 변경안

### 메시지 생성 모드 응답

```typescript
const generateResponseSchema = z.object({
  ok: z.boolean(),
  data: z.object({
    messages: z.array(z.object({
      label: z.string(),    // "부드러운 표현", "격식있는 표현", "친근한 표현"
      text: z.string(),     // 생성된 메시지 본문
    })),
    usage: usageResultSchema,
  }),
});
```

### 말투 교정 모드 응답

```typescript
const correctResponseSchema = z.object({
  ok: z.boolean(),
  data: z.object({
    diagnosis: z.string(),    // 한줄 진단
    corrections: z.array(z.object({
      label: z.string(),      // "부드럽게 바꾼 버전", "격식 있게", "간결하게"
      text: z.string(),       // 교정된 문장
    })),
    detail_analysis: z.object({
      overall_score: z.number(),
      category_scores: categoryScoresSchema,
      signals: z.array(signalSchema),
      warnings: z.array(z.string()),
    }),
    usage: usageResultSchema,
  }),
});
```
