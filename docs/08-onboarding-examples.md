# 06. 온보딩 예시 문장

## 개요

처음 방문한 사용자가 서비스를 쉽게 체험할 수 있도록 칩 형태로 예시 문장을 제공합니다.
칩 클릭 시 입력 폼에 자동으로 문장이 입력되어 바로 분석/생성을 체험할 수 있습니다.

## 타겟 사용자 고려사항

**주 사용자층**: 50대, 30대 초반, 60대

**특징**:
- 디지털 커뮤니케이션에 익숙하지 않은 중장년층
- 세대 간 소통에서 말투 조정 필요
- 비즈니스/가족 메시지 작성에 어려움

**UI/UX 원칙**:
- 예시는 실생활에서 자주 겪는 상황 중심
- 문장은 짧고 명확하게 (20~40자)
- 시나리오를 쉽게 이해할 수 있는 표현 사용

## 예시 문장 (칩 형태)

### 메시지 생성 모드 (generate)

사용자가 상황을 설명하면 적절한 메시지 3개를 생성해주는 모드

| 시나리오 | 예시 문장 | 길이 |
|----------|----------|------|
| 상사 | "내일 연차 사용하고 싶어요" | 14자 |
| 동료 | "회의 시간 변경 요청드립니다" | 15자 |
| 고객 | "배송이 지연되어 죄송합니다" | 15자 |
| 부모님 | "오늘 저녁에 집에 갈게요" | 14자 |
| 자녀 | "숙제 다 했는지 확인해줘" | 13자 |
| 친구 | "주말에 같이 영화 볼래?" | 13자 |

### 말투 교정 모드 (correct)

작성한 메시지의 말투를 분석하고 개선안을 제공하는 모드

| 시나리오 | 예시 문장 | 길이 |
|----------|----------|------|
| 상사 | "내일 좀 쉬고 싶은데요 괜찮을까요?" | 20자 |
| 동료 | "회의 시간 바꾸면 안 될까요? 다른 일정이 생겨서요" | 28자 |
| 고객 | "배송 늦어진 것 같은데 확인 좀 해주세요" | 23자 |
| 부모님 | "오늘 늦을 것 같아요 걱정 마세요" | 19자 |
| 자녀 | "숙제 했어? 빨리 하고 자야지" | 16자 |
| 친구 | "주말에 영화 보러 갈래? 재미있을 것 같아" | 23자 |

## 칩 표시 우선순위

**1순위** (자주 사용하는 상황):
- 상사: "내일 연차 사용하고 싶어요"
- 동료: "회의 시간 변경 요청드립니다"
- 부모님: "오늘 저녁에 집에 갈게요"

**2순위** (필요 시 추가):
- 고객: "배송이 지연되어 죄송합니다"
- 친구: "주말에 같이 영화 볼래?"

## 구현 가이드

### 프론트엔드

```typescript
const ONBOARDING_EXAMPLES_GENERATE = [
  { scenario: 'boss', text: '내일 연차 사용하고 싶어요' },
  { scenario: 'colleague', text: '회의 시간 변경 요청드립니다' },
  { scenario: 'to_parent', text: '오늘 저녁에 집에 갈게요' },
];

const ONBOARDING_EXAMPLES_CORRECT = [
  { scenario: 'boss', text: '내일 좀 쉬고 싶은데요 괜찮을까요?' },
  { scenario: 'colleague', text: '회의 시간 바꾸면 안 될까요? 다른 일정이 생겨서요' },
  { scenario: 'to_parent', text: '오늘 늦을 것 같아요 걱정 마세요' },
];
```

### 칩 클릭 시 동작

1. 칩 클릭
2. 입력 폼에 예시 문장 자동 입력
3. 시나리오 자동 선택 (예시에 맞게)
4. 사용자가 말투만 선택하면 바로 분석/생성 가능

### 접근성

- 칩 크기: 터치하기 쉽게 충분한 크기 (최소 44x44pt)
- 폰트 크기: 중장년층을 위해 16px 이상
- 색상 대비: WCAG AA 기준 이상
- 스크롤 가능: 모든 예시를 가로 스크롤로 탐색 가능

## 향후 개선 방향

- 사용자별 최근 사용 시나리오 학습하여 맞춤 예시 제공
- A/B 테스트로 클릭률 높은 예시 발굴
- 계절/이벤트별 예시 문장 제공 (설날, 추석 등)
