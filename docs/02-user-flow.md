# 02. 사용자 플로우 & 화면 구조

## 1. 화면 구조

**v1 (현재): 4페이지**

```
홈(입력) → 로딩(분석+광고) → 결과(점수표) → 제안(개선문장)
```

**v2 (피봇): 3페이지 + 선택적 상세 1페이지**

```
홈(입력) → 로딩(생성/교정+광고) → 결과(바로 복사 가능한 메시지)
                                        └─ [교정 모드 한정] 상세 톤 분석 (선택)
```

## 2. 홈 화면

```
┌─────────────────────────────┐
│  이 말투 어때                  │
│  오늘 남은 횟수: 3회            │
│                              │
│  ┌──────────┬──────────┐     │
│  │ 메시지 생성  │ 말투 교정  │     │  ← 탭 (기본: 메시지 생성)
│  └──────────┴──────────┘     │
│                              │
│  누구에게 보내나요?              │
│  [자녀에게] [부모에게] [직장상사]  │  ← 시나리오 칩
│  [동료] [거래처] [친구] [연인]    │
│                              │
│  어떤 느낌으로?                 │
│  [부드럽게] [단호하게]           │  ← 톤 칩
│  [격식있게] [캐주얼하게]          │
│                              │
│  어떤 상황이든 편하게 설명해주세요   │  ← 가이드 텍스트
│  ┌─────────────────────┐     │
│  │ (생성) 예: 아들이 내일      │     │
│  │ 생일인데 축하 메시지를      │     │  ← 텍스트 입력
│  │ 보내고 싶어요             │     │
│  │                        │     │
│  │ (교정) 보내려는 문장을      │     │
│  │ 입력해주세요              │     │
│  └─────────────────────┘     │
│  상황을 더 자세히 적으면       │
│  결과가 좋아져요    20/800    │  ← 동적 힌트 + 글자수
│                              │
│  ┌─────────────────────┐     │
│  │      생성하기 / 교정하기   │     │  ← CTA 버튼
│  └─────────────────────┘     │
└─────────────────────────────┘
```

### 탭별 차이점

| 요소 | 메시지 생성 탭 | 말투 교정 탭 |
|------|------------|------------|
| placeholder | "어떤 상황인지 설명해주세요" | "보내려는 문장을 입력해주세요" |
| CTA 버튼 | "생성하기" | "교정하기" |
| 시나리오/톤 | 동일 | 동일 |
| 최소 글자수 | 10자 | 20자 (현행 유지) |

### 시나리오 옵션 (7개)

| 시나리오 | 설명 | 타겟 연결 |
|---------|------|----------|
| 자녀에게 | 부모가 자녀에게 보내는 메시지 | 50대+ 핵심 시나리오 |
| 부모에게 | 자녀가 부모에게 보내는 메시지 | 20~30대 |
| 직장상사 | 윗사람에게 보내는 메시지 | 30대 핵심 시나리오 |
| 동료 | 같은 레벨 직장 동료 | 30대 |
| 거래처 | 비즈니스 외부 소통 | 30대 |
| 친구 | 친구 간 소통 | 전 연령 |
| 연인 | 연인 간 소통 | 전 연령 |

### 톤 옵션 (4개)

| 톤 | 설명 |
|----|------|
| 부드럽게 | 따뜻하고 배려하는 느낌 |
| 단호하게 | 명확하고 확고한 느낌 |
| 격식있게 | 존댓말, 공식적인 느낌 |
| 캐주얼하게 | 편하고 친근한 느낌 |

## 3. 로딩 화면

```
┌─────────────────────────────┐
│                              │
│         (로딩 애니메이션)        │
│                              │
│   (생성) AI가 메시지를 만들고 있어요  │
│   (교정) AI가 문장을 살펴보고 있어요 │
│                              │
│        [인터스티셜 광고]          │
│                              │
└─────────────────────────────┘
```

- 현행 2-phase 타임아웃 유지 (8s load + 3s show)
- 뒤로가기 시 확인 다이얼로그 유지
- API 호출과 광고 로딩 병렬 실행 (현행 유지)

## 4. 결과 화면

## 5. 상세 톤 분석 화면 (교정 모드 전용, 선택적)

```
┌─────────────────────────────┐
│  ← 결과로 돌아가기              │
│                              │
│  🔍 상세 톤 분석                │
│                              │
│  전체 점수: 72점               │
│  ████████████░░░ 72/100      │
│                              │
│  감정·태도      78점           │
│  예의·존중      85점           │
│  명확·전달력    70점           │
│  상황·관계 적합  65점           │
│  갈등 안정성    62점           │
│                              │
│  ⚠️ 시그널                    │
│  "~하세요" 표현이 명령조로       │
│  느껴질 수 있어요               │
│                              │
└─────────────────────────────┘
```

- 기존 v1의 5카테고리 점수 분석 기능을 그대로 유지
- 메인 플로우에서 제외하되, 원하는 사용자만 접근 가능
- 교정 모드에서만 노출 (생성 모드에서는 분석할 원문이 없음)

## 6. 쿼터 소진 시 플로우

```
[홈] 제출 시도
  │
  ├─ 쿼터 있음 → [로딩] → [결과]
  │
  └─ 쿼터 없음 → [UsageLimitNotice 배너]
                    │
                    └─ "충전하기" → [AdBottomSheet]
                                    │
                                    └─ 광고 시청 완료 → +1회 충전 → 다시 제출
```

- 현행 광고 충전 플로우 그대로 유지

## 7. v1 → v2 변경 요약

| 항목 | v1 (현재) | v2 (피봇) |
|------|----------|----------|
| 페이지 수 | 4개 | 3개 + 선택적 1개 |
| 입력 모드 | 단일 (교정만) | 탭 2개 (생성/교정) |
| 시나리오 | 2개 (비즈니스/개인) | 7개 (자녀에게, 부모에게, 직장상사, 동료, 거래처, 친구, 연인) |
| 톤 선택 | 3개 (일반/조심/편안) | 4개 (부드럽게/단호하게/격식있게/캐주얼하게) |
| 결과 화면 | 5카테고리 점수표 + 별도 제안 페이지 | 한줄 진단 + 메시지 3개 (한 화면) |
| 점수 분석 | 메인 결과 | 교정 모드에서 "상세 분석 〉" 링크로 선택적 접근 |
| 결과까지 탭 수 | 최소 5탭 | 최소 3탭 |
